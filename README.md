# Intelligent Vision Assistant System for Visually Impaired

An interactive, real-time computer vision application that detects everyday surroundings and translates them into live spoken guidance for visually impaired users.

## ✨ Key Features
* **Real-time Detection:** Powered by YOLOv4-Tiny to run smoothly on standard laptops without requiring a heavy GPU.
* **Smart Audio System:** Uses multithreading to announce objects without breaking or freezing the video frame.
* **Directional Awareness:** Tells the user if an obstacle is on their left, right, or straight ahead.

## 🛠️ Built With
* Python 3.10
* OpenCV (Deep Learning Network Module)
* Pyttsx3 (Text-to-Speech Engine)
* NumPy
